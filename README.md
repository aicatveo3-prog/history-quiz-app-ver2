# 한국사 기출 학습

폴더의 `모의고사 열기.html`을 더블클릭하여 실행합니다. 이미 열어 둔 사이트는
새로고침(F5)하면 새 학습 화면으로 바뀝니다. 설치나 인터넷 연결 없이 사용합니다.
`site/dist` 폴더가 함께 있어야 합니다.

## 학습 순서

1. 제74회·제78회·제79회 심화 중 회차를 선택합니다.
2. 한 문제의 원본 사료·사진·보기를 읽고 답 번호를 고릅니다.
3. **정답 확인**을 누르면 정오답, 정답 번호, 핵심 단서와 해설이 표시되고, 문제 아래에 **자세한 해설**(자료 읽는 법, 보기별 분석, 배경 이론, 암기 포인트)이 펼쳐집니다.
4. 해설을 읽고 **다음 문제**를 눌러 넘어갑니다.
5. 50문항을 마치면 원본 배점에 따른 점수와 오답을 확인합니다. **해설 보기**로 복습합니다.

상단의 **문제 이동** 바를 끌어 원하는 문항으로 바로 이동합니다. **문항 번호로 이동**을
펼치면 1~50번을 직접 누를 수 있으며, 현재 문제·정답·오답·확인 전 상태가 구분됩니다.
이동해도 선택한 답과 해설 확인 기록은 유지됩니다. 50번을 먼저 푼 경우에는
**아직 안 푼 문제로** 버튼으로 미학습 문항에 돌아갈 수 있습니다.

시간 제한은 없습니다. 확인한 답은 수정할 수 없으며, 이전 문제에서 해설을 다시
읽을 수 있습니다. 처음부터 다시 풀면 해당 회차의 학습 기록이 새 풀이로 바뀝니다.
원본 PDF 열기도 지원합니다. 번호 선택은 키보드 방향키로도 가능합니다.
정답을 확인한 뒤에는 문제 카드의 `문제 보기` 스위치를 꺼서 문제를 접고 해설만 볼 수 있습니다(다시 켜면 펼쳐집니다).

## 단원별 풀기 · 특수 분류

메인 화면 위쪽 탭으로 풀이 방식을 고릅니다.

- **회차별 풀기**: 기존 방식(회차 50문항).
- **단원별 풀기**: 시대 9개, 주제 78개. 시대 전체 또는 주제 하나를 골라 여러 회차의 문항을 이어서 풀 수 있습니다(550문항 전부 정확히 한 주제에 들어 있음).
- **특수 분류**: 유물·문화유산(31), 지역사(18), 시대 비교·통사(10). 이 문항들은 시대 단원에도 그대로 들어 있습니다(양쪽에 보임).

묶음의 진도는 묶음마다 따로 저장되어 회차별 기록과 섞이지 않습니다(`korean-history-study-v2-<묶음 id>`).
묶음 안에서는 `제72회 47번`처럼 원래 회차와 번호가 표시되고, 지역사 문항에는 지역 태그가 붙습니다.
해설은 해설이 있는 회차(74·78·79회) 문항에서만 나옵니다.

분류 원고는 `content/unit-map.json`입니다(시대 → 주제 → 문항 `"회차-번호"`, 특수 분류는 `special`).
고친 뒤 `python tools/build_units.py`를 실행하면 `dist/units.js`가 만들어집니다. 550문항 누락·중복, 존재하지 않는 문항은 빌드에서 검사합니다.
주제 id는 시대 id와 목록 순서(`goryeo-3`)로 만들어지므로, 주제 순서를 바꾸면 id와 저장된 묶음 진도가 달라집니다.

## 화면 디자인

기존 초록색 디자인을 바탕으로 제목, 여백, 카드, 답안 버튼과 해설을 다듬었습니다.
문제 이동 영역은 간결하게 줄이고, 해설의 핵심 단서를 따로 강조했습니다.
넓은 화면에서는 문제와 해설을 나란히, 작은 화면에서는 세로로 배치합니다.
시안 전환 메뉴는 풀이 화면에서 제거했습니다. 이전에 선택했던 시안과 관계없이
개선된 기존 디자인으로 열리며, 학습 기록은 유지됩니다.
이전 시안 이미지는 `dist/designs.html`에 참고용으로 보관했습니다.

## 넓은 화면의 풀이 배치

900px보다 넓은 화면에서는 왼쪽에 **문제와 선택지(①~⑤), 정답 확인/다음 문제 버튼**을 고정하고(스크롤해도 따라옴),
오른쪽 넓은 칸에는 **정답 결과와 해설만** 보여 줍니다. 해설을 읽는 동안 문제와 보기가 계속 보입니다.
본문 폭은 최대 1840px까지 넓어지고, 문제 칸 너비는 문제 이미지의 가로세로 비율과 화면 높이로 계산해
나머지 폭을 모두 해설 칸이 씁니다. 해설 칸이 900px 이상이면 자세한 해설을 좌우 두 묶음
(자료 읽는 법·보기별 분석 / 배경 이론·암기 포인트)으로 나란히 보여 줍니다.
가능하면 문제 전체가 한 화면에 들어오며, 화면이 낮으면 문제 칸 안에서만 스크롤됩니다(선택지 줄은 항상 보임).
정답을 확인하면 위치를 자동으로 맞추고, 해설 맨 아래에도 `다음 문제` 버튼이 있습니다.
좁은 화면(모바일)은 문제 → 선택지 → 정답/해설 순서로 세로 배치합니다. 스타일은 `dist/split.css`입니다.

### 문제 접기

정답을 확인하면 문제 카드 제목 줄에 `문제 보기` 스위치(켜짐=초록/오른쪽, 꺼짐=회색/왼쪽)가 나타납니다. 끄면 문제 이미지와 선택지가 접히고, 문제 칸은
제목·스위치·`다음 문제` 버튼만 남은 좁은 카드가 되어 나머지 폭을 모두 해설이 씁니다. 다른 문제로 넘어가면 다시 펼쳐진 상태로 시작합니다.
(답을 고르기 전에는 접을 수 없습니다. 예전의 `문제 크게 보기` 창은 없앴습니다.)

### 화면 배분 도구

문제와 해설 사이의 **막대를 끌어서** 문제 칸과 해설 칸의 너비 비율을 직접 바꿀 수 있습니다(넓은 화면 전용, 별도 버튼 없음).

- 막대를 더블클릭하면 자동 맞춤(화면 높이에 맞춰 자동 계산)으로 돌아갑니다.
- 키보드: 막대에 포커스를 두고 ←/→(Shift는 크게), Home/End(최소/최대), Enter(자동 맞춤)
- 정한 비율은 이 브라우저에 저장되어 다음 문제와 다음 방문에도 유지됩니다. 비율은 화면 너비에 대한 %로 저장하므로
  창 크기가 바뀌어도 해설 칸 400px·문제 칸 340px 아래로는 줄어들지 않게 자동 보정됩니다.
- 문제 칸을 넓히면 문제 이미지가 커져서 화면보다 길어질 수 있으며, 이때는 문제 칸 안에서 스크롤됩니다(선택지 줄은 항상 보임).

## 자료와 해설

원본 문제 PDF에서 150문항을 개별 이미지로 잘라 사진·사료·선택지를 보존했습니다.
정답과 배점은 제공된 원본 정답표에서 추출했습니다. 원본 `한능검 기출` 폴더는
수정하지 않았습니다.

원본에는 해설이 없어 **150문항의 학습용 해설을 별도 작성**했습니다. 공식 해설이
아니며, 각 문항의 단서·정답인 이유·헷갈리는 보기와의 차이를 설명합니다.
일부 세부 사항은 국사편찬위원회 우리역사넷과 한국학중앙연구원 자료를 확인했고,
해당 문항에 참고 링크를 넣었습니다. 핵심 학습 기능은 오프라인에서도 동작합니다.

## 회차 추가 (문제·정답만)

제70~73회, 제75~77회, 제80회 심화는 **문제와 정답만** 들어 있고 해설은 아직 없습니다(홈에는 `정답 · 해설 준비 중`으로 표시되고,
정답을 확인하면 `해설 준비 중` 안내가 나옵니다). 이론 정리 페이지는 해설이 있는 74·78·79회 150문항만 다룹니다.

새 회차 PDF(`한능검 기출/…n회 심화 문제.pdf`, `…정답.pdf`)를 폴더에 넣은 뒤 아래처럼 추가합니다.

```
python tools/add_exams.py 81 82
```

- 문제 PDF는 스캔 이미지라서 Tesseract(OCR, kor+eng)로 문항 번호 위치를 찾아 문항별 이미지로 자릅니다.
  1~50번이 순서대로 정확히 한 번씩 찾아져야 하며, 그렇지 않으면 멈추고 알려 줍니다.
- 정답표는 텍스트에서 읽습니다(동그라미 숫자 형식과 일반 숫자 형식 모두 지원, 50문항·100점 검증).
- 필요한 도구: Python의 `pdfplumber`, `pypdfium2`, `Pillow`, 그리고 `C:/Program Files/Tesseract-OCR`.
- 기존 회차(`dist/exams.js`의 다른 항목)는 건드리지 않고 새 회차만 덧붙입니다.
- 나중에 해설을 붙일 때는 `content/<회차>.tsv`와 `content/detail-<회차>a/b.json`을 만들고
  `build_explanations.py` → `build_details.py`를 실행합니다. (이론 정리는 별도 원고를 쓰므로 영향을 받지 않습니다.)

## 자세한 해설

기출 풀이 화면의 해설은 새로 만드는 중입니다. 현재는 **제77회 50문항**에만 해설이 있고,
나머지 회차는 정답만 확인할 수 있습니다(`해설 준비 중`). 정답을 확인하면 문제 옆에 아래 4단 해설이 표시됩니다.

1. **자료 읽는 법**: 지문의 어떤 단서로 시대·인물·사건을 확정하는지
2. **보기별 분석**: ①~⑤ 각각이 왜 정답이거나 오답인지 (내가 고른 답은 따로 표시)
3. **배경 이론**: 해당 주제의 연표와 개념 정리
4. **암기 포인트**: 헷갈리는 쌍을 구분하는 한 줄 요약

원고는 `content/<회차>.tsv`(간단 해설)와 `content/detail-<회차>a/b.json`(a는 1~25번, b는 26~50번)입니다.
고친 뒤 `python tools/build_explanations.py`, `python tools/build_details.py`를 실행하면
`dist/explanations.js`, `dist/details.js`가 만들어집니다. 빌드는 정답 일치와 보기 개수(5개)를 검사하며,
50문항 중 일부만 있는 회차도 허용합니다(해설이 없는 문항은 `해설 준비 중`으로 표시).
`자료 읽는 법`·`배경 이론`·`암기 포인트`에 줄바꿈(`\n`)을 넣으면 화면에서 단락이 나뉩니다.
공식 해설이 아니라 학습용으로 새로 작성한 내용입니다.

## 이론 정리

상단 메뉴의 **이론 정리**(`dist/theory.html`)에서 150문항의 해설을 9개 시대, 85개 주제로 묶어 볼 수 있습니다.
주제 한 줄에 출제 횟수와 문항(예: `74-11` = 제74회 11번), 암기 포인트가 표로 나오고,
누르면 배경 이론·헷갈리는 구별·출제 문항이 펼쳐집니다. 시대 선택, 키워드 검색,
'2회 이상 출제만' 필터, 모두 펼치기/접기를 지원하고 인쇄하면 전부 펼쳐집니다.

- 문항 번호(`74-11`)를 누르면 이론 정리 화면 위에 **작은 문제 창**이 열립니다(`dist/theory-quiz.js`).
  문제 이미지를 보고 선택지 번호를 누르면 **바로 채점**되며 해설과 보기별 분석이 항상 펼쳐져 나타납니다.
  `다시 풀기`와 같은 주제의 다른 기출로 바꾸기도 가능합니다(방향키는 선택하지 않고 포커스만 옮깁니다). `닫기`, `이론으로 돌아가기`, `Esc`, 창 바깥 클릭으로
  돌아오며, `기출 페이지로 이동`을 누르면 해당 문항의 전체 풀이 화면으로 갑니다.
  Ctrl/Cmd/Shift+클릭이나 가운데 버튼 클릭은 작은 창 없이 바로 기출 페이지로 이동합니다.
  작은 창의 풀이 기록은 이 페이지를 닫기 전까지만 기억하며 기출 풀이의 진도 기록에는 영향을 주지 않습니다.
- 문제 풀이 화면에서 정답을 확인하면 해설 칸의 버튼으로 해당 주제의 이론 정리로 이동합니다(해설이 없는 문항도 이동 버튼은 나옵니다).
- 주제 묶음은 `content/theory-map.json`에서 고칩니다(150문항이 정확히 한 번씩 들어가야 합니다).
- 고친 뒤 `python tools/build_theory.py`를 실행하면 `dist/theory-data.js`가 만들어집니다.
  문항 누락·중복은 빌드에서 검사합니다.
- 기본 내용은 74·78·79회의 원래 해설에서 가져온 것이며, 그 원고는 **이론 정리 전용**으로
  `content/theory-source/`(`74/78/79.tsv`, `detail-74·78·79a/b.json`)에 따로 보관합니다.
  기출 풀이 화면의 해설(`content/<회차>.tsv`)을 새로 쓰거나 지워도 이론 정리는 바뀌지 않습니다.
- `build_theory.py`는 `dist/theory-data.js`와 함께 문제 창용 해설 `dist/theory-explanations.js`
  (`window.THEORY_EXPLANATIONS`, `THEORY_DETAILS`)도 만듭니다. 이론 정리의 작은 문제 창은 이 파일만 사용합니다.
- **보강**(노란색 블록)은 기출 해설에 없는 추가 내용입니다. 한국민족문화대백과사전 등으로 확인한 출처 링크가 붙어 있고(점선 링크는 위키백과 보조 출처), `보강 내용 보기`로 숨길 수 있습니다.
  보강은 `content/theory-extra.json`에서 따로 관리하며, 항목마다 주제 id(`theme`), 유형(짝꿍·흐름·비교), 내용, 출처가 필요합니다. 이 파일을 고치고 `python tools/build_theory.py`를 실행하면 반영됩니다.
- 보강 후보 전체 목록(채택하지 않은 항목 포함)은 작업 폴더의 `tmp/theory-candidates.md`에 남겨 두었습니다.

## 진도 저장

선택한 답, 확인 여부, 현재 문제를 같은 브라우저에 자동 저장합니다. 페이지를 닫거나
새로고침한 뒤 이어 풀 수 있습니다. 비공개 모드나 저장 제한 환경에서는 기록이
유지되지 않을 수 있으며 화면에 안내를 표시합니다.

파일 직접 열기와 로컬 HTTP 접속의 기록은 각각 따로 저장됩니다. 이전 모의고사
방식의 저장 기록은 삭제하지 않았으며, 새 학습 진도는 별도 저장 공간을 사용합니다.

## 파일 구성 및 재생성

- `dist/index.html`, `dist/styles.css`, `dist/learning.css`, `dist/study.js`: 화면과 학습 동작
- `dist/polish.css`: 기존 초록색 디자인 개선
- `dist/designs.html`, `dist/previews`: 이전 시안 참고 이미지
- `dist/designs.css`, `dist/designs.js`: 이전 시안 소스 보관 (현재 화면에서는 로드하지 않음)
- `dist/exams.js`: 문항·정답·배점·이미지 정보
- `dist/explanations.js`: 기출 풀이 화면의 기본 해설 (`content/<회차>.tsv`에서 생성, 현재 77회)
- `dist/details.js`: 기출 풀이 화면의 자세한 해설 (`content/detail-<회차>*.json`에서 생성, 현재 77회)
- `content/77.tsv`, `content/detail-77a/b.json`: 기출 풀이 화면 해설 원고
- `content/theory-source/`: 이론 정리 전용 원고(74·78·79회 원래 해설). `build_theory.py`만 사용
- `dist/theory-data.js`, `dist/theory-explanations.js`: 이론 정리 데이터와 문제 창 해설 (`build_theory.py`에서 생성)
- `dist/assets`: 문항별 이미지, 페이지 이미지, 원본 PDF 사본
- `tools/import_exams.py`: 문제지 변환과 정답 추출
- `tools/crop_questions.py`: 문항 이미지 생성
- `tools/build_explanations.py`: 해설 누락과 정답 일치를 검사하여 JS 생성
- `tools/build_details.py`: 자세한 해설 원고를 검사하여 `dist/details.js` 생성
- `tools/build_units.py`: 단원별·특수 분류 원고(`content/unit-map.json`)를 검사하고 `dist/units.js` 생성
- `tools/fix_group_72.py`, `tools/patch_72_group.py`: 72회 47·48번 공통 지문 보정(이미지·텍스트 데이터). 문항 이미지를 전체 재생성하면 `fix_group_72.py`를 다시 실행합니다.
- `tools/verify.mjs`: 학습 흐름 검증
- `content/questions-text/`: 전 회차(70~80) 550문항 텍스트 데이터. 자세한 내용은 해당 폴더의 `README.md` 참고
- `tools/extract_text_layer.py`, `extract_question_text.py`, `merge_verified_text.py`: 텍스트 데이터 생성 도구

전체 자료를 재생성할 때에는 Python으로 `import_exams.py`, `crop_questions.py`,
`build_explanations.py` 순서로 실행합니다. pdfplumber, pypdfium2, Pillow가 필요합니다.
해설만 수정한 경우에는 `build_explanations.py`만 실행하면 됩니다.

## 검증

`node site/tools/verify.mjs`로 150문항 순차 풀이, 정답 확인 전 해설 숨김, 다음 문제
진입 조건, 확인한 답의 수정 차단, 회차별 100점 채점, 부분 채점, 진도 복구,
오답 필터, 자유로운 문항 이동과 이동 후 기록 복구, 저장이 제한된 환경에서의 동작을 검사합니다.

실제 브라우저에서는 정답·오답 제출과 해설 표시, 다음·이전 문제, 새로고침 복구,
문제 확대, 결과 복습, 1280px·390px·320px 화면 배치를 확인했습니다. 앱 미리보기의
파일 URL 제한 때문에 브라우저 검증에는 로컬 HTTP 서버를 사용했습니다.
개선한 기존 디자인에서 1440px·390px·320px 배치, 모바일 답 선택·정답 확인·해설 표시,
시안 선택 메뉴 제거와 새로고침 후 학습 진도 유지도 확인했습니다.
개인 컴퓨터에서 사용할 수 있도록 로컬 파일로 제작했으며 공개 배포하지 않았습니다.
