# 문제 텍스트 데이터 (제70~80회 심화, 총 550문항)

문제 이미지(`dist/assets/<회차>/question-NN.jpg`)를 다시 읽지 않고 쓸 수 있도록 텍스트로 변환한 데이터입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `<회차>.json` | 회차별 50문항 배열 (70~80) |
| `all.jsonl` | 전체 550문항, 한 줄에 한 문항 |
| `ocr/<회차>.json` | 73·74·78·79회의 Tesseract 원본 초안 (참고용) |

## 필드

| 필드 | 설명 |
|---|---|
| `exam`, `number` | 회차, 문항 번호 |
| `points` | 배점 |
| `answer` | 정답 번호 (1~5) |
| `page`, `image` | PDF 쪽수, 문제 이미지 경로 |
| `stem` | 발문 (끝에 ` [N점]` 포함) |
| `passage` | 지문·자료·표·연표 (줄바꿈은 원문 레이아웃 기준) |
| `choices` | 선택지 5개 (`①` 등 기호 제외) |
| `choices_are_images` | 선택지가 그림이면 true |
| `text` | 발문+지문+선택지를 합친 전체 텍스트 |
| `figures` | 그림·표 정보 `{kind, description, text}` |
| `notes` | 변환 메모 |
| `verified` | 검수 여부 |
| `source` | 추출 방식 |
| `ocr_text` | (OCR 기반 회차만) Tesseract 원문 |

## 표기 규칙

- `<u>…</u>`: 원문의 밑줄. 발문에 "밑줄"이 있는 문항에서만 지문·선택지에 표시합니다.
- `[왼쪽 말풍선]`, `[연표]`, `[그림] …` 같은 대괄호 표기는 원문에 없는 설명용 주석입니다.
- `□ ○ → ✻` 등 특수 기호와 80회의 옛 한글(ᄌᆞ ᄉᆞ ᄃᆡ ᄒᆞ)은 원문 글리프대로 복원했습니다.

## 추출 방식

| 회차 | 방식 | 정확도 |
|---|---|---|
| 70·71·72·75·76·77·80 | PDF 텍스트 레이어를 pdfplumber로 추출 | 글자는 원문 그대로 |
| 73·74·79 | 글자가 벡터 윤곽선이라 Tesseract OCR 초안 → 이미지 대조 교정 | 교정본, 일부 항목은 불확실 |
| 78 | 전체가 스캔 이미지 → 위와 동일 | 교정본, 일부 항목은 불확실 |

## 한계

- 70·71·72·75·76·77·80회: `figures`에 위치(bbox)만 있고 그림 설명은 없습니다. 그림 선택지 문항은 `choices_are_images: true`이며 `choices`가 비어 있습니다.
- 표·연표처럼 2차원 자료는 읽는 순서대로 나열되어 구조가 흐트러질 수 있습니다 (예: 70회 9번).
- 73·74·78·79회: 그림 선택지는 `[그림] 설명` 형태의 서술입니다. 작은 한자나 캡션은 오독 가능성이 있습니다.
  - 교정자가 불확실하다고 표시한 문항
    - 73회: 3, 6, 10, 14, 19, 21, 26, 33, 36, 45, 46, 49
    - 74회: 3, 8, 13, 18, 19, 21, 22, 24, 28, 30, 31, 43, 50
    - 78회: 6, 10, 14, 21, 26, 28, 40, 45, 47, 48
    - 79회: 5, 6, 11, 17, 18, 24, 27, 28, 30, 35, 38, 41, 44, 46
- 해설은 없습니다. 해설이 있는 회차는 `../detail-*.json`을 참고하세요.
